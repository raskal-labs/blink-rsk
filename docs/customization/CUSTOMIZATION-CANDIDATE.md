## Review and provenance

The three new guarded patches apply after the six accepted repairs, on upstream `a90b4423c8b7a86770c24a7eaa6c13b0a5904b18` (18.7.0/1097). Guards reject every changed input, new-path collision and repeated application before mutation. Customization changes exactly 20 paths; all nine patches together change exactly 31 paths, enumerated in [the combined allowlist](../../scripts/customization-combined-paths.json).

- `b779f6f`: versioned preferences/action/input-mode model, retained-row selection/capture bridge and Swift/JavaScript tests.
- `f1f04d3`: ordered input queue, pipe ownership/cancellation, paste gate, keyboard/key adapters and real-pipe regressions.
- `7152dce`: dock, D-pad, workspace, session transitions, appearance drafts, native settings/layout integration and five main-app source registrations.
- `05969b7`: combined guards/preflight, macOS queue integration gate, workflow allowlist and early source/patch/build receipts.

D-pad provenance is the reviewed standalone panel from `ShogunPanda/blink@c1bff729`, with its license retained; the adapter uses Blink's existing key encoding. No fork configuration, signing, rendering queue or session policy is imported. Select All adapts the bundled retained-row algorithm and passes a node to `selection.extend` in the visible-last-row branch. Input delivery uses bounded nonblocking writes rather than an unbounded fork retry loop. Darwin `F_SETNOSIGPIPE` use was checked against [Apple's descriptor implementation](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/kern/kern_descrip.c); no global signal policy is changed.

The accepted provider startup-cleanup parity/polling and the two narrow Snips-resign/gesture-detachment repairs remain composed and guarded. None is described as repairing a scrolling freeze or the withdrawn Files sync report. Renderer/backpressure, Mosh mouse/protocol/full-scrollback experiments and remote multiplexer-history retrieval remain research.

- [ ] Enable/drag/close/reopen D-pad; tap and hold arrows in local shell, SSH and Mosh; release/cancel/drag, session switch, background and modal opening stop repeat without input reaching another session.
- [ ] Hide/show, lock/unlock and Input/Select and Scroll compose correctly; terminal taps do not reopen the keyboard in locked/selection mode.
